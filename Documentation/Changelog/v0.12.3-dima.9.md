New since v0.12.3-dima.8:

Quick Open
+ The Cmd+O file list now shows a hint footer with the keys for opening a file: `Enter` to go to it, `Cmd+Enter` to open it in a new pane, `Shift+Enter` to replace the current pane, and `Alt+Enter` to open it in a pane to the left. // The labels follow your [[Settings]] → Links & Panes choice, so the `Cmd` and `Shift` hints swap if you set links to replace panes by default. The footer respects the "show prompt instructions" preference and only appears when a file or search result is selected.
