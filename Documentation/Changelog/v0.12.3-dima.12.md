New since v0.12.3-dima.11:

Navigation
+ Added a **Focus Left Sidebar** command, bound to `Mod+1`, that moves keyboard focus into the left sidebar's file tree so you can move through notes with the arrow keys (Up/Down to move, Left/Right to collapse/expand folders). // Unlike toggling the sidebar, this never closes it — it opens it if needed and always parks focus inside.
- Moved the **Header 1** shortcut from `Mod+1` to `Mod+Alt+1` to make room. // Headers 2–6 keep their existing `Mod+2`…`Mod+6` shortcuts.
- The keyboard focus highlight in the file tree no longer fades as it moves. // The `.2s` background fade lagged behind arrow-key movement, leaving a smeared, half-drawn highlight when moving quickly. It now snaps to each item instantly.

Reliability
- Fixed a freeze where the panes stopped responding to everything — **New Note** created files but never opened them, clicking a note in the sidebar did nothing, and `Cmd+W` was dead — until you restarted. // A note that failed to render used to take down the whole window with it. Each pane is now isolated: a note that can't be displayed shows an error in its own pane (with a **Try again** button) while the rest of the app keeps working.
- Fixed content search listing the same note twice when it matched both by name and by body text. // A note that satisfied `named X or with X` on both counts now appears once.
