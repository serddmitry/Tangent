New since v0.12.2:

Links & Navigation
+ Links now follow on a plain click, with a pointer cursor to match.
+ Links whose target is already open in the thread are highlighted.
+ Added support for links and embeds to files outside the workspace. // Shell-escaped paths are handled too.
- Fixed the caret getting stuck inside a link's hidden brackets when arrowing vertically or clicking to the right of a link.
- Fixed link modifier classes staying stuck after the modifier key was released.

Inline Backlinks
+ Added optional inline backlinks at the bottom of each note.
+ Backlinks are shown on virtual notes, without force-opening the details panel.
+ Notes already open in the thread are marked in the inline backlinks list.
- Linked reference snippets now update while editing, and keep their highlighting after a rename.

Thread View
+ The spine is only drawn when panes are actually covered; panes hold a fixed width.
+ The horizontal scrollbar is now a slim, subtle pill with more contrast.
- The slide-in animation only plays when appending, and no longer flashes the scrollbar.
- Overscroll space is only reserved in focus and typewriter modes.

Editing
+ Added keyboard shortcuts for toggling checkboxes. // Checkboxes also got a bit more breathing room before their text.
+ Rendered diagrams can expand into the note margins.
- Mermaid's DOM-injected error diagram no longer appears on a parse failure.

Appearance
+ Desaturated the light theme's accent fills into a pastel green.
+ Blockquotes have a gap between the bar and the text.
- The open-backlink title highlight is lighter in light mode.
- Link preview tooltips no longer grow from center when appearing.

Under the Hood
+ Renderer logs are recorded to the log file, and a throw in the renderer no longer freezes it.
+ A pane's search panel opens on click or Cmd+F rather than on hover.
