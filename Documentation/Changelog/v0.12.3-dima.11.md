New since v0.12.3-dima.10:

Wiki Links
- Clicking a `[[link]]` to a note that doesn't exist yet now creates a real note on disk, instead of opening an in-memory placeholder. // Previously the placeholder was never written out, so the note only half-existed: renaming it left the source `[[link]]` untouched and unlinked, and the file was missing on disk.
- Renaming such a just-created note now rewrites the `[[links]]` that point at it, the same as renaming any other note. // Before, typing `[[hello]]`, clicking it, then renaming the page to `hello 2` left the original page still saying `[[hello]]` — pointing at nothing.
