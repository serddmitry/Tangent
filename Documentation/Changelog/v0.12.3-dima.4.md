New since v0.12.3-dima.3:

Saving & Data Safety
- Fixed edits made just before quitting or closing a window being lost. The save on exit now completes before the window tears down, instead of racing (and sometimes losing to) shutdown.
- Fixed a rejected save silently discarding your changes. If a write doesn't reach disk, the note now stays marked unsaved and retries, rather than quietly dropping the edit and clearing the unsaved dot. // This was the core of a data-loss bug: a save that failed looked identical to one that succeeded.
- Fixed a workspace reload replacing unsaved edits with the older copy from disk. In-memory changes are now kept when a reload arrives.
+ Notes now also save at least every 15 seconds while you keep typing, so a long uninterrupted burst can no longer sit entirely in memory unsaved between pauses.
